# Archive

Earlier figures and runner scripts that are no longer on the website (explainer figures, the
"Super El Niño, explained" story series, global impact statistics and the official heat/fire
outlook figure). They still work; run them from the repository root so they can find the shared
modules:

```bash
PYTHONPATH=. python archive/fig1_nino_regions_map.py
PYTHONPATH=. python archive/run_story.py
```

Output goes to `figures_public/` as before.
